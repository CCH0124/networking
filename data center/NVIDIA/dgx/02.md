# NVIDIA DGX SuperPOD: Next Generation Scalable Infrastructure for AI Leadership Reference Architecture Featuring NVDIA DGX B200

## Key Components of the DGX SuperPOD

DGX SuperPOD 架構旨在將最先進模型訓練的效能最大化、擴展至 Exaflops 等級的運算效能、為儲存設備提供極高效能，並全面支援企業、高等教育、研究機構及公部門等各類客戶。它是 NVIDIA 主要研發系統的數位分身，這代表該公司的軟體、應用程式和支援體系，皆已率先在相同的架構上完成測試與驗證。透過採用擴充單元（SUs），系統部署時間從數個月大幅縮減至數週。運用 DGX SuperPOD 設計能有效縮短新世代模型與應用程式的解決方案開發時間與產品上市時程。

DGX SuperPOD 是 NVIDIA 關鍵核心組件的完整整合，同時也納入了經認證可在 DGX SuperPOD 環境中良好運作的合作夥伴儲存解決方案。

### 重點整理

* **極致運算與擴充能力**：DGX SuperPOD 架構專為最先進的 AI 模型訓練打造，效能可擴展至 Exaflops 級別，並提供極高效能的儲存與多領域應用支援。
* **NVIDIA 內部研發架構的「數位分身」**：該架構與 NVIDIA 自身的研發系統一致，所有軟體、應用程式與支援體系皆已經過相同環境的嚴格測試與驗證。
* **大幅縮短部署與開發週期**：透過可擴充單元（SUs）設計，系統建置時間從數月縮短至數週；同時加速新世代模型與應用的產出（time-to-solution）與上市時程（time-to-market）。
* **整合生態系元件與認證儲存**：DGX SuperPOD 深度整合 NVIDIA 核心硬體與軟體，並結合經官方認證的合作夥伴儲存解決方案。

## NVIDIA DGX B200 System

NVIDIA DGX B200 系統（圖 1）是一座 AI 算力中心，協助企業拓展商業創新與最佳化的前沿領域。DGX B200 系統採用 8 顆 GPU 配置，以史上最強大的晶片提供突破性的 AI 效能。其搭載的 NVIDIA Blackwell GPU 架構具備最新技術，能在處理幾類最大規模的 AI/ML 工作負載時，將數個月的運算時間縮短至數天甚至數小時。

相較於 DGX H200 系統，DGX B200 系統的幾項核心亮點包括：

* 72 PFLOPS 的 FP8 訓練效能與 144 PFLOPS 的 FP4 推論效能
* 第五代 NVIDIA NVLink 高速互聯技術
* 高達 1,440 GB 的整合式 HBM3 記憶體

### 重點整理

* **強大的企業級 AI 運算樞紐**：NVIDIA DGX B200 搭載最新 Blackwell 架構晶片，採用 8 顆 GPU 配置，專為突破企業創新與最佳化極限所打造。
* **算力大幅躍進**：在處理大型 AI/ML 工作負載時，能將原本需數月的計算週期縮短至數天甚至數小時。
* **相較 H200 的顯著規格提升**：
    * 提供高達 **72 PFLOPS FP8 訓練**與 **144 PFLOPS FP4 推論**效能。
    * 導入**第五代 NVIDIA NVLink** 高速互聯技術。
    * 具備高達 **1,440 GB 的整合式 HBM3 記憶體**。

## NVIDIA InfiniBand Technology


InfiniBand 是一項具備高效能、低延遲以及支援 RDMA 功能的網路技術，在最嚴峻的運算環境中歷經逾 20 年驗證，可提供頂尖的節點間（inter-node）網路連線效能。InfiniBand 持續演進，並引領著現代資料中心網路的效能標準。

NDR 世代的 InfiniBand（即 NDR）每方向具備最高 400 Gbps 的峰值速率與極低的埠對埠延遲，且向下相容先前世代的 InfiniBand 規範。InfiniBand 的價值遠不止於峰值頻寬與低延遲，它還提供諸多額外功能以最佳化整體效能，包含適應性路由（Adaptive Routing, AR）、結合 SHARP™ 的集合通訊卸載、透過 SHIELD™ 進行動態網路自我修復，並支援肥樹（Fat-Tree）、蜻蜓（Dragonfly）以及多維環圈（Multi-dimensional Torus）等多種網路拓撲，用以打造規模極為龐大的運算架構與系統。

### 重點整理

* **20 年實戰驗證的高效能互連網路**：InfiniBand 具備高頻寬、超低延遲與 RDMA（遠端直接記憶體存取）特性，在最嚴苛的運算環境中已驗證超過 20 年，持續領先資料中心網路效能。
* **NDR 世代規格突破**：單向最高傳輸速率可達 400 Gbps，擁有極低的埠對埠（port-to-port）延遲，並具備向下相容前代規格的優勢。
* **豐富的進階效能優化機制**：超越純頻寬與延遲考量，提供適應性路由（Adaptive Routing）、SHARP 集合通訊卸載，以及 SHIELD 動態網路自我修復功能。
* **靈活支援多元網路拓撲**：相容胖樹（Fat-Tree）、蜻蜓（Dragonfly）與多維環圈（Torus）等主流拓撲架構，能支撐構建出規模極大的運算網格與系統。


## Runtime and System Management

DGX SuperPOD 參考架構（RA）代表了打造高效能資料中心的最佳實踐做法。這些系統在呈現給客戶與終端使用者的方式上具備高度彈性。所有 DGX SuperPOD 的部署作業皆採用 NVIDIA Base Command Manager 軟體進行管理。

DGX SuperPOD 可以在本地端（On-premises）完成部署，這意味著客戶能如同傳統系統一樣，自行擁有並管理實體硬體。此部署形式可落實於客戶自有的資料中心內部，或是主機代管於商業資料中心，但硬體的資產所有權仍完全歸客戶所有。


### 重點整理

* **資料中心建置最佳實踐**：DGX SuperPOD 參考架構（Reference Architecture, RA）代表了構建高效能資料中心的標準化典範做法。
* **統一管理中樞**：所有 DGX SuperPOD 部署均統一由 NVIDIA Base Command Manager 軟體進行集中化管理與調度。
* **彈性的本地端（On-premises）部署架構**：客戶可選擇自建資料中心或將硬體託管（Co-location）於商業資料中心；兩種形式下客戶皆保留對實體硬體的完整所有權與管理自主權。

## Design Requirements
DGX SuperPOD 旨在透過緊密耦合的整體架構配置，將系統瓶頸降至最低，從而提供最佳效能與應用程式的可擴展性。每一個子系統都經過縝密的設計，以達成此一目標。此外，整體架構依舊保有彈性，以便能夠依據資料中心的需求進行客製化調整，進而更完善地整合至現有的資料中心環境之中。

### System Design
DGX SuperPOD 專為客戶特定的多節點 AI 與高效能運算（HPC）應用工作負載進行最佳化：

* 以每單元包含 32 台 DGX B200 系統的可擴展單元（SUs）為基礎的模組化架構。
* 完整經過測試驗證的系統可擴充至 4 組 SUs，亦可根據客戶需求打造更大規模的部署。
* 單一機櫃可支援兩台 DGX B200 系統，以便調整機櫃布局以滿足不同資料中心的要求。
* 經過認證可在 DGX SuperPOD 環境中運作的合作夥伴儲存設備。
* 由 NVIDIA Enterprise Experience (NVEX)提供包含運算、儲存、網路及軟體的全方位系統技術支援。

### Compute Fabric

* 運算網格採用軌道最佳化（Rail-optimized）、平衡式的完整胖樹（Full-Fat Tree）拓撲結構。
* 整體設計全域採用託管型 NDR 交換器，以便對整個網路網格提供更優質的管理能力。
* 該網路網格旨在支援最新版本的 SHARP 功能。

### Storage Fabric (High Speed Storage)
儲存網格為共享儲存設備提供高傳輸頻寬，並具備以下特性：

* 獨立於運算網格之外，從而將儲存本身與應用程式兩者的效能最大化。
* 為每台 DGX B200 系統提供至少 40 GBps 的單節點傳輸頻寬。
* 透過 InfiniBand 或聚合乙太網路 RDMA（RoCE）架構提供儲存連線，以發揮極致效能並將 CPU 開銷降至最低。
* 具備高度彈性，能夠橫向擴展以滿足特定的容量與頻寬需求。
* 具備與管理節點的連線能力，用以提供獨立於運算節點之外的儲存存取通道。

### In-Band Management Network

* 帶內管理網路網格基於乙太網路架構，用於節點佈建、資料傳輸、網際網路存取，以及使用者必須存取的其他各項服務。
* 運算節點與管理節點的帶內管理網路連線以 200 Gbps 的速率運作，並透過網路綁定（bonding）技術來提升系統韌性。

### Out-of-Band Management Network

帶外（OOB）管理網路連接了所有的基板管理控制器（BMC）連接埠，以及其他應當與使用者維持實體隔離的設備。交換器管理網路則是帶外網路的一個子集，能提供額外的安全性與系統韌性。

### Storage Requirements

DGX SuperPOD 運算架構必須與高效能、平衡配置的儲存系統相互搭配，以將整體系統效能最大化。DGX SuperPOD 旨在採用兩套各自獨立的儲存系統——高效能儲存（HPS）與使用者儲存，分別針對輸送量、平行 I/O，以及更高的 IOPS 和元數據（metadata）等關鍵運作負載進行最佳化。

### High-Performance Storage

高效能儲存（HPS）是由 DGX SuperPOD 認證儲存合作夥伴透過 InfiniBand 連線儲存設備所提供，其在工程設計與測試時充分考量了以下特質：

* 具備高效能、高韌性的 POSIX 風格檔案系統，專為跨多節點的多執行緒讀寫作業進行最佳化。
* 支援 InfiniBand 或乙太網路上的 RDMA 功能。
* 利用本地系統記憶體（RAM）對資料進行透明快取。
* 以透明方式調用本地端快閃儲存裝置（Flash），作為讀寫快取使用。

具體的儲存網格拓撲、容量大小與元件配置，皆在 DGX SuperPOD 設計流程中由認證儲存夥伴規劃決定。

### User Storage

使用者儲存（User Storage）與高效能儲存（HPS）不同之處在於，它是在帶內管理網路網格上提供 NFS 共享目錄，以供多種用途使用。它通常用於「家目錄（home directory）」類型的用途（特別是在部署 Slurm 的叢集中）、管理員暫存空間、高可用性（HA）配置中 DGX SuperPOD 元件（例如 Base Command Manager）所需的共享儲存，以及存放日誌檔案。

考量到這一點，使用者儲存具備以下需求：

* 必須具備 100 Gb/s 的連線能力。
* 專為高元數據（metadata）效能、高 IOPS 以及檢查點儲存（checkpointing）等關鍵企業功能所設計。這與針對平行 I/O 和大容量進行最佳化的高效能儲存（HPS）有所不同。
* 透過乙太網路（Ethernet）使用 NFS 協定進行通訊。

在 DGX SuperPOD 中，使用者儲存通常可藉由既有已部署的 NFS 伺服器來滿足需求，做法只需建立新的匯出目錄（export），並開放給 DGX SuperPOD 的帶內管理網路存取即可。因此，本 DGX SuperPOD 參考架構並未對使用者儲存進行詳細描述。然而，我們對使用者儲存要求具備最低 100 Gb/s 的頻寬。
